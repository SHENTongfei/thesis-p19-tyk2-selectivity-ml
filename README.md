# 基于机器学习的 TYK2 炎症通路激酶靶向配体发现研究

> 以 TYK2 在银屑病与炎症性肠病中的关键作用为切入点，构建靶向配体发现模型，支撑新型免疫调节剂研发。

## 一、方法

- **模型**：双向 LSTM + 全局注意力池化

- **输入**：SMILES 字符级 token 序列
- **训练规模**：2499 条样本，2 类
- **标签协议**：rel
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练
